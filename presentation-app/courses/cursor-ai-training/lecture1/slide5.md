# Core Interface Overview

## 🏗️ **Main Components**

### **📝 Editor Pane**

Enhanced with AI suggestions and inline assistance

### **📁 Sidebar**

Traditional file explorer + AI chat interface

### **⌨️ Command Palette**

AI-enhanced command search and execution

### **📊 Status Bar**

AI model status and usage indicators

---

## **🤖 AI Integration Points**

### **✨ Inline Suggestions**

- **Tab** to accept suggestions
- **Escape** to dismiss
- **Partial acceptance** with arrow keys

### **💬 Chat Interface**

- **Cmd/Ctrl + L** to open chat
- Context-aware conversations
- File and code references

### **🧠 Context Awareness**

- Automatic file and project understanding

### **📚 Docs Feature**

- AI can read documentation via Chat

### **⚡ Command Mode**

- **Cmd/Ctrl + K** for quick actions
- Natural language commands
- Contextual operations
